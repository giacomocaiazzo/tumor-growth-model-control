# Tumor Growth Model Control

A MATLAB and Simulink project on nonlinear analysis and control of a tumor-growth model. The study includes LQR, feedback linearization, sliding mode control and EKF state estimation.

## Project files

| Folder | Description |
| --- | --- |
| [model/](model/) | Model parameters and initial conditions. |
| [analysis/](analysis/) | Equilibria, phase portraits and bifurcations. |
| [lqr/](lqr/) | LQR design and simulation. |
| [feedback-linearization/](feedback-linearization/) | Feedback linearization and error dynamics. |
| [sliding-mode/](sliding-mode/) | Sliding mode control and symbolic calculations. |
| [state-estimation/](state-estimation/) | Sliding mode control with an EKF. |
| [docs/](docs/) | Project report and usage guide. |

## How to use

Open the project folder in MATLAB. Run the analysis scripts individually or use the Simulink model for the control method of interest.

See the [usage guide](docs/USAGE.md) for the execution order and the [report](docs/Tumor_growth_model_control.pdf) for the complete study.
